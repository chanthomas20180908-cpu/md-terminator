# MD Terminator

本地 Markdown 文件浏览器：文件夹树、多文档页签与草稿，内置彩色编辑部及三种开源配色。

```sh
npm install
npm run dev
```

在终端显示的地址打开。`npm run build` 运行类型检查与生产构建。

## 文件工作区

使用桌面 Chrome / Edge 访问本地地址（localhost / 127.0.0.1）。点击“打开文件夹”，在系统对话框中授予只读访问权限。左侧“文件夹”展示目录与 `.md` / `.markdown` 文件，子目录按需加载，点击文件打开顶部页签。悬停根文件夹时显示刷新按钮，更新目录和已展开的子目录，并重新读取当前目录中正在阅读的文件。首版没有自动文件监听。取消选择保留当前工作区；浏览器不支持目录 API 时可使用单文件导入。

左侧“文档目录”跟随当前阅读页签，点击标题定位。侧边栏紧接顶部工具栏，右侧的紧凑页签支持切换、关闭及键盘左右/Home/End；重复打开目录内同一文件会激活已有页签。同名文件显示父目录，悬停可查看来源。更换文件夹保留已打开页签及其来源。切换页签保留阅读位置。

“新建草稿”打开独立输入页签；手动输入后按 Cmd/Ctrl+Enter 阅读，粘贴立即阅读，点击“编辑草稿”可继续修改。“粘贴”从剪贴板创建新草稿，不覆盖当前文件。所有磁盘文件只读，没有删除、重命名或覆盖保存功能，草稿通过“导出 .md”下载。

关闭的页签可从“历史”重新打开。目录、页签、草稿、历史和外观仅在页面内存中保存，刷新或关闭后清空，需要重新选择文件夹。文字不上传，无 AI 调用。

授权目录内的相对 Markdown 链接可打开新页签；支持当前文档和目标文档锚点。相对图片只从授权目录范围内读取，切换文件后释放图片对象 URL。目录外路径不会自动访问，单文件导入或草稿中的相对资源没有目录权限时会显示提示。远程图片仍需手动加载，加载会访问图片地址。原始 HTML 不执行，危险链接保留解析器过滤。大文档暂未使用虚拟滚动。

### 验证边界

`npm test` 覆盖目录枚举与自然排序、路径边界、权限错误，以及原有 Markdown / 卡片 / 结构图回归。`npm run build` 检查类型与生产构建。系统目录授权、剪贴板、真实文件切换、阅读位置、移动布局及四主题视觉仍需在实际浏览器验收；自动测试通过不等于已完成浏览器验收。

## 阅读外观

顶部“外观”支持 10–32px 字号、1.0–3.0 倍正文行距与四个主题，即时生效，仅存本次页面内存。恢复默认回到彩色编辑部 / 14px / 1.85 倍。

主题使用各项目色板适配本站排版，并非官方阅读器移植：
- Solarized：https://github.com/altercation/solarized （MIT）
- Nord：https://github.com/nordtheme/nord （MIT）
- Catppuccin：https://github.com/catppuccin/catppuccin （MIT）

阅读页顶部“导出 .md”下载当前文章的原始 Markdown（UTF-8），不包含页面样式或主题设置。文件名为 `文章标题_YYYYMMDD-HHMMSS-ffffff.md`，使用导出时本机时间；标题中的文件名特殊字符会被替换。历史文章打开后同样可以导出。

文章按一级至六级标题拆成嵌套章节卡片，同级标题各自独立，较低级标题归入最近的上级章节。标题前的引言和无标题文章使用独立卡片。代码块及引用内的标题不会拆分正文卡片；原始 Markdown 导出保持不变。

中文标点附近的加粗与斜体通过 remark-cjk-friendly 的只解析扩展识别（例如 `**可以借鉴：**以原文…`），不插入空格或改写原始 Markdown，导出内容保持不变。

悬停章节卡片时，右上角浮现复制图标（键盘聚焦按钮也会显示），不额外预留顶部空间，可覆盖正文；悬停子卡片时仅显示该子卡片的图标：复制该章标题、正文及全部子章节的原始 Markdown，不包含同级或上级章节；引言与无标题文章也支持复制。保留代码、表格及加粗标记，复制成功或失败均有提示。

## 结构图试验

自动识别“文书模板知识 → 取材指引知识 → 任务资料绑定（上传材料、知识库）→ 任务上下文 → 审查任务／生成任务”的完整连续纯文本组合，每个节点包含一行说明，任务资料绑定不附加说明。支持空行或段内换行，按原文顺序排布；箭头不代表额外业务关系。可切换结构图与原文，主题随外观设置变化。缺失节点、顺序不符或说明混杂时保留普通文本。首版为此类结构的试验模板，不自动还原任意图表。章节复制及导出仍使用原始 Markdown。

章节结构树：连续纯文本以“……模板”开头、带有 `3`、`3.2`、`3.2.X` 等明确章节编号时，可识别为章节树。按编号前缀嵌套；“内容属性：”“关联…”和“子章节可…”说明附在前一个章节下。必须存在至少三个节点及明确父子层级，缺父级、编号重复或内容不明确时保留原文。支持结构树／原文切换，后续解释段落保持原位置；不推断新的业务关联，复制和导出不改写原文。
