# MD Terminator

本地 Markdown 阅读工具，首个模式为「彩色编辑部」。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 执行类型检查与生产构建。

粘贴 GPT 回答或导入 Markdown 文件，切换阅读模式，使用目录跳转章节。支持 GFM 表格、任务列表及代码高亮。原文不重写；HTML 不执行。远程图片需手动加载，点击后浏览器会访问图片地址。

文本和阅读状态保存在当前浏览器当前站点的 localStorage；清空按钮删除当前文本，浏览器清除站点数据可删除全部保存状态。无服务器存储和 AI 调用。剪贴板受浏览器权限限制，可直接手动粘贴。

模式样式集中在 src/style.css，Markdown 渲染在 src/main.tsx。首版只提供固定模式。超大文档未使用虚拟滚动；移动端编辑与预览纵向排列。
